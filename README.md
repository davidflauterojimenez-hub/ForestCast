# ForestCast

## Descripción general

ForestCast es un modelo de deep learning que predice el riesgo de deforestación a escala global utilizando imágenes satelitales (Sentinel-2 y Landsat). A diferencia de los métodos reactivos que detectan deforestación después de que ocurre, ForestCast usa redes neuronales convolucionales (CNN) para pronosticar qué áreas tienen mayor probabilidad de ser deforestadas en el futuro, permitiendo intervenciones proactivas de conservación.
